Det meste på nettet er tekst. Hvor god en nettside er, handler derfor mye om én ting: hvor lett det
er å lese den. Det heter **typografi**, og det er tre ting som betyr mest.

## Prøv selv

Teksten under er vanskelig å lese. Juster de tre glidebryterne til den føles behagelig – og se hva
som skjer når du går for langt den andre veien.

## Linjeavstand

`line-height` bestemmer hvor høy hver linje er, og dermed hvor mye luft det er mellom linjene. Den
skrives ofte *uten* enhet:

```css
body {
  line-height: 1.6;
}
```

`1.6` betyr 1,6 ganger skriftstørrelsen. Det fine med å skrive det uten enhet, er at det følger med
når skriftstørrelsen endres: store overskrifter og små fotnoter får den samme luftige rytmen.

For brødtekst er **1,4–1,7** et godt sted å starte. Overskrifter trenger mindre, rundt **1,1–1,3** –
store bokstaver med mye luft mellom linjene ser ut som to separate overskrifter.

## Linjelengde

Lange linjer er slitsomme: øyet mister tråden når det skal finne starten på neste linje. Korte linjer
er hakkete. De fleste leser best med **45–75 tegn** per linje.

Den enkleste måten å styre det på, er enheten `ch`. `1ch` er bredden på tegnet «0» i skrifta, så
`65ch` er omtrent 65 tegn:

```css
main {
  max-width: 65ch;
  margin: 0 auto;
}
```
