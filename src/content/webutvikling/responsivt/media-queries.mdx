Relative enheter tar deg langt. Men noen ganger må oppsettet *endre seg*: tre kolonner på en PC
er for trangt på en mobil, der det heller bør være én. Til det har CSS **media queries**.

## Regler som bare gjelder noen ganger

En media query er en blokk med CSS-regler som bare gjelder når et krav er oppfylt:

```css
.kort-rad {
  display: grid;
  gap: 12px;
}

@media (min-width: 700px) {
  .kort-rad {
    grid-template-columns: 1fr 1fr;
  }
}
```

Les det slik: *Når skjermen er minst 700 piksler bred, skal kortene stå i to kolonner.* På smalere skjermer
gjelder bare regelen over, og kortene står under hverandre.

Reglene inni en media query er vanlige CSS-regler, og kaskaden virker som før: står media queryen etter den
vanlige regelen, vinner den når den gjelder.

## Hvor skal bruddpunktene være?

Bredden der oppsettet endrer seg, kalles et **bruddpunkt** (*breakpoint*). Det er fristende å velge breddene
til bestemte telefoner, men det finnes tusenvis av skjermstørrelser. Gjør heller slik:

1. Start smalt, og gjør vinduet sakte bredere.
2. Når siden begynner å se rar ut – for lange linjer, for mye tom plass, kort som kunne stått ved siden av
   hverandre – legger du inn et bruddpunkt akkurat der.

Det er *innholdet* som bestemmer bruddpunktene, ikke telefonene.
