Nå som siden har en tydelig struktur, er det lett å style den. Du kan bruke taggene direkte som
selektorer – `header`, `nav`, `main` og `footer` – uten å finne på klasser.

## Topp og bunn

```css
header {
  background-color: #1d3557;
  color: white;
  padding: 16px;
}

footer {
  background-color: #f1faee;
  padding: 16px;
  font-size: 14px;
}
```

<Tips>

`body` har som standard litt margin rundt hele siden. Vil du at toppen og bunnen skal gå helt ut til
kanten, setter du `body { margin: 0; }`. Da må du gi `main` padding i stedet, så teksten ikke klistrer
seg til kanten.

</Tips>

## Menyen

En meny skal sjelden se ut som en vanlig punktliste. To regler fjerner det som gjør den til en liste:

```css
nav ul {
  list-style: none;
  padding: 0;
}
```

- `list-style: none` fjerner kulepunktene.
- `padding: 0` fjerner innrykket nettleseren gir lister.

Legg merke til selektoren `nav ul`: den betyr *en `<ul>` som ligger inni en `<nav>`*. Andre lister på
siden blir ikke berørt. På samme måte treffer `nav a` bare lenkene i menyen:

```css
nav a {
  color: white;
  text-decoration: none;
}
```
